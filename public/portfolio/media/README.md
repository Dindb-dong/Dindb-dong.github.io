# 썸네일 이미지 폴더

현재 포트폴리오가 사용하는 프로젝트 이미지와 영상을 저장합니다. `legacy/public/thumbnails`는 동결된 보관본이므로 수정하지 않습니다.

## 파일 명명 규칙

- `proj_{프로젝트ID}_{이미지번호}.png` 또는 `.jpg`
- 예시:
  - `proj_1_1.png` - 첫 번째 프로젝트의 첫 번째 이미지
  - `proj_1_2.jpg` - 첫 번째 프로젝트의 두 번째 이미지
  - `proj_2_1.png` - 두 번째 프로젝트의 첫 번째 이미지

## 사용 방법

1. 프로젝트 썸네일 이미지를 이 폴더에 저장하세요.
2. 파일명은 위의 규칙에 따라 명명하세요.
3. 기존 PNG, JPG, JPEG 이미지와 MP4, MOV 영상을 유지합니다.
4. 프로젝트별 파일 목록과 순서는 `src/portfolio-data.js`의 `MEDIA`에서 관리합니다. 목록 표지는 등록된 첫 이미지이며, 이미지가 없으면 첫 미디어를 사용합니다.
5. 프로젝트 상세는 이미지를 우선해 최대 세 미디어를 표시합니다. 경력 앱의 자료 선택과 캡션은 `src/experience-content.js`에서 관리합니다.
